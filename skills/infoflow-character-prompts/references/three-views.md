# 人物三视图模板

一人一张；只重生成失败的角色，不拿上一个角色改。提示词由固定模板和该角色完整版中的**人物描述原文**组成。原稿附有旧画幅、构图或景别指令时，画幅与构图采用下方模板。用户同一轮明确要求换装时，使用只更新指定内容后的角色描述。

```
生成一张横版16:9人物设定图，纯白色背景，画面中只有同一个人物。左侧为该人物正面头肩大特写，正脸直视镜头，神态与人物描述一致，头顶、发型、颈部和双肩完整，五官清晰，记忆点清楚可见。右侧从左到右依次为该人物的正面全身、标准90度侧面全身、背面全身，三个全身像大小一致、互不重叠，头顶到鞋底完整。人物自然站立，双手自然下垂，双腿自然站直，不拿任何物品，不插兜、不抱胸。四个视图的脸、发型、妆容、配饰、服装、鞋袜和身材比例完全一致。画面中不出现任何文字、箭头、边框、色卡、水印或其他人物。真人短剧明星定妆照质感。核心角色采用主演级妆发与精修，半柔侧光塑造清晰五官、明亮眼神和头肩轮廓，保持真实演员比例、自然肌理和面料质感。
人物描述：【完整版人物描述】
```
