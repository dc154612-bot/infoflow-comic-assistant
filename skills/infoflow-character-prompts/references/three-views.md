# 人物三视图模板

一人一张；只重生成失败的角色，不拿上一个角色改。提示词由固定模板和该角色完整版中的**人物描述原文**组成。原稿附有旧画幅、构图或景别指令时，画幅与构图采用下方模板。用户同一轮明确要求换装时，使用只更新指定内容后的角色描述。

```
生成一张横版16:9人物设定图，纯白色背景，画面中只有同一个人物。左侧为该人物正面头肩大特写，正脸直视镜头，神态与人物描述一致，头顶、发型、颈部和双肩完整，五官清晰，记忆点清楚可见。右侧从左到右依次为该人物的正面全身、标准90度侧面全身、背面全身，三个全身像大小一致、互不重叠，头顶到鞋底完整。人物自然站立，双手自然下垂，双腿自然站直，不拿任何物品，不插兜、不抱胸。四个视图的脸、发型、妆容、配饰、服装、鞋袜和身材比例完全一致。发夹和耳饰按人物自身左右侧固定，服装的领口、缝线、纽扣与面料在不同角度保持同一结构。画面中不出现任何文字、箭头、边框、色卡、水印或其他人物。真人短剧明星定妆照质感。核心角色采用明星主演级选角、精细妆发和时装大片级定妆。头肩特写以有神的眉眼、清楚的骨相转折、精细妆面与发丝层次为重点。全身三视图清楚呈现服装的设计剪裁、材质层次及配饰细节，侧面可辨鼻梁至下颌的轮廓，背面可辨发式和服装结构。统一明亮的影棚白平衡，用大面积侧前方柔光与轻柔补光保留眼神光、面部立体感和可见的面料明暗。
人物描述：【完整版人物描述】
```
