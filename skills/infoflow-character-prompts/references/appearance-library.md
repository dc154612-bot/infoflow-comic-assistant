# 人物美型库

以下条目供角色定妆选用。当前剧本与已确认的人设优先，五官、妆发和服装可分别选用。剧本要求人物相像时，保留指定的相像程度与区分线索。换装沿用已定面容与体态，配件和局部特征的位置按人物自身左右记录。

### 3. 记忆点

- 中景可见（主记忆点）：狼尾短发、空气刘海、高马尾、特定发色、蝴蝶结发饰、珍珠发夹、耳骨夹、额前一缕碎发、背头、浅棕发色、银色耳钉、银链项链、腕表、发冠款式、标志性主色。
- 近景可见：泪痣、梨涡、唇珠、小虎牙、断眉、眼下小痣、酒窝。

### 4. 长辈与路人

普通长辈、路人：干净体面，五官端正。豪门长辈：保养得宜，保留与剧本相符的年龄感，发型一丝不苟，珠宝点睛（珍珠项链、翡翠镯、腕表），面料高级（真丝、羊绒、改良旗袍、定制西装），神态端庄威严，反派可写“眼神刻薄”。古装长辈：凤冠或珠翠，织金刺绣，神态威严。
