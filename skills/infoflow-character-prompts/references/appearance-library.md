# 真人信息流人物美型库

用于真人短剧的角色定妆。核心角色以高颜值主演定妆照为基准。现代女角取韩剧主演的精致眉眼、柔净脸部线条和有光泽的妆发，核心男角取男明星骨相和清晰的头肩轮廓。真实演员比例和布料支撑真人摄影质感，主演级柔光与精修提高中景里的辨识度和吸引力。画风采用真人实拍式影视定妆。

## 真人信息流的成片质感

| 维度 | 定妆标准 |
| --- | --- |
| 女角五官和妆面 | 韩剧女主演的精致度。眉形清楚，眼神明亮，睫毛和眼尾过渡可见。面部轮廓柔净，鼻唇有细微起伏，匀净底妆配合角色气质选择唇色与腮红。清冷、甜美和知性可用不同脸型、眼型与神态呈现。 |
| 男角骨相和妆发 | 男明星式立体眉骨、眼窝层次、高挺鼻梁与清楚下颌。协调头肩比例、颈线与发型体积。少年感角色可用蓬松碎发和层次便服，成熟角色可用露额短发和利落肩线。 |
| 灯光与精修 | 白底参考图用明亮大面积柔光，补出眼神光和衣料细节。面部明暗过渡柔和，白色背景、肤色与浅色服装都能分辨。皮肤匀净通透，头发有受控光泽、纹理清楚。 |
| 全身造型 | 从领口、肩线、腰线到裙摆、裤脚和鞋形成完整轮廓。用材质和叠搭做出精致度，如浅色同系靠缎面与绉纱分层，深色便服靠针织、衬衣与牛仔的质感差异分层。配饰围绕一种主要视觉记忆点搭配。 |

质感参考用于决定五官的精修程度、妆发组织、造型完整度、光线和材质表现。每个新角色的脸、发型和穿搭以当前剧本及用户已确认设定设计。

## 选型顺序

1. 从剧本提取年龄、职业、生活环境、当前场合和主要人物关系。已经确认的身形、发型、制服和剧情换装优先。剧本里未明确的设计标为「设计建议」。
2. 为每个核心角色选一种主气质，再从下表取一套匹配的五官、妆发和穿搭方向。先让面部有主演感，再用脸型、眼型和发型轮廓区分同剧角色。下表的穿搭是起点，按职业、年代、预算感与场合换成合理的单品。确定具体人物时，每项只写一个确定值。
3. 锁定脸型、眼型、发型轮廓和一个中景可见的记忆点。服装主色随造型版本记录，妆容、服装和配饰按换装需求调整。脸型、眼型和整体体态随角色复用，剧情明确要求改变某个特征时记录变化范围。
4. 并排比较同剧核心角色。脸型、眼型、发型轮廓、服装主色中至少三项有明显差异，主记忆点不重复。有演员参考图、制服或其他设定锁定外观时，优先遵守锁定项，再用可调整的轮廓、配饰或神态做区分。

## 从角色处境选气质

| 角色处境 | 候选气质与造型依据 |
| --- | --- |

| 逆袭、复仇、大女主 | 明艳大气系、酷飒系、清冷系。先区分她在场合里是公开掌控、低调反击还是暂时隐忍 |

| 擅长讨好、维持好感的女配 | 甜美公主系、甜美初恋系。可与女主同属甜美气质，通过不同脸型、发型轮廓、主色和眼神区分 |
| 强势或擅长操控局面的女配 | 妩媚御姐系、明艳大气系、温柔知性系。先判断她在剧情中希望别人如何看待自己 |
| 霸总、豪门继承人 | 冷峻霸总系、清冷禁欲系。按职业和场合选择肩线、外套和面料 |
| 暖男男二、竹马 | 温润如玉系、阳光少年系。用柔和眼神与服装剪裁体现亲近感 |
| 年下、小奶狗 | 奶狗系、阳光少年系。根据剧本年龄、行动方式和出入场合确定青春感 |
| 渣男、浪子 | 痞帅不羁系、温润如玉系。后者可以用礼貌的外表与短暂冷下来的目光体现落差 |
| 古装王爷、权臣、将军或侠客 | 古装矜贵妖冶系、古装冷峻侠将系。根据身份、时代设定和动作量决定衣领、袖宽、发冠与层次 |
| 古装女性 | 先选符合角色的气质，再按时代、身份、场合替换发式、妆面、衣领、面料和首饰 |

## 按场合调整

- **长辈和路人**。用真实年龄感、整齐造型和合适的职业服装。豪门长辈可以通过挺括羊毛、暗纹丝缎、清楚肩线和一件玉饰塑造讲究的生活质感。
- **校园、制服和工作场合**。以剧本场合决定着装，普通大学场合用符合身份的便服。衣色受限时，从发型轮廓、脸型、眉眼、体态和表演神态做区分。造型完成度看领肩轮廓、面料层次、鞋型与妆发是否配合。
- **落魄、病中、普通家庭场景**。使用现实场合能穿的叠搭、柔和底妆和有质地的普通面料，维持角色的发型轮廓与辨识点。精致感可来自整齐领口、干净发丝或合身剪裁。
- **古装女性**。可用月白交领与白玉细簪表现清冷，用浅粉齐胸襦裙与小珠花表现活泼，用正红暗花大袖与金色腰封表现明艳。结合时代和身份选衣领、发髻、配饰与袖型。
- **民国、港风**。先核对时代、职业和外出场合，再选对应面料、领型、鞋与发式。民国办公室可用短卷发和合身挺括的大翻领，港风聚会可用侧分长发与绒质外套。

## 角色一致性与镜头表现

- **主演定妆检查**。女角看眉眼是否清亮、五官是否协调上镜，男角看眉骨、鼻梁和下颌在正侧面是否有层次。核心角色的精致度通过柔光、妆发与修图体现，剧本需要的年龄感和同剧人物差异清楚可辨。
- **中景记忆点**。优先用能看清的发长、刘海分线、发饰轮廓、贴近脸部的耳饰或强识别的主色组合。痣、梨涡和唇珠作为近景的第二记忆点。
- **神态变化**。为核心角色内部定好日常和压力下的表现，必要时加反击、登场等剧情指定状态。用目光、眉眼和嘴角的变化写表情。定妆提示词选定一个神态，分镜动作随剧情调用适合的状态。
- **换装复用**。使用同一个角色的基本脸型、眼型、体态与长期记忆点。新服装记录场合、主色、剪裁和要替换的配饰。生成该套三视图时，所有角度使用同一版妆发与服装。
- **同类型共演示例**。两位甜美女角可以分别选「小鹅蛋脸、齐肩直发、薄荷绿开衫」和「心形脸、半扎长卷发、酒红蝴蝶结」。前者神态外放，后者保持笑容时长时间直视。两人的辨识依靠头部轮廓、主色和表演同时拉开。
