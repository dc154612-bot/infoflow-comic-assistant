# 人物提示词

## 本轮输入

- 写人物提示词时，使用当前剧本及用户确认的人物设定。已有本剧拆解稿时，用其中的出场人物和角色关系辅助定位。设计新造型或按要求换装时，读[真人信息流人物美型库](references/appearance-library.md)的类型与「可复用造型元素」，按年代、身份、场合和气质选择可搭配的细节。当前剧本与确认稿优先。用户给本剧的质感参考图时，提取精修程度、打光、妆发轮廓和面料表现。已确认的人物身份参考图用于锁定角色。
- 只做三视图时，读取[三视图模板](references/three-views.md)及该角色完整版原文。使用用户已确认的版本，用户要求完整流程且尚未确认角色版本时，可使用本次生成的完整版。缺少完整版时索取材料，或先完成完整流程的人物提示词步骤。同一轮明确要求换装并更新三视图时，把指定修改应用到已确认的人物描述，用修改后的版本生成这份三视图提示词。
- 限定某一个角色时，逐条对照该角色原稿。新增设定标注「设计建议」。用户只要人物或三视图提示词时，交付提示词。用户要求生成三视图或跑完整流程时，有生图工具就按模板生成一人一张的参考图。生图工具不可用时，交付可复制提示词并说明图片尚未生成。

## 造型和输出

核心角色默认**男帅女美，镜头第一眼有主演感**。现代题材采用韩剧主演级选角和时装棚拍质感，古装采用国风古装剧主演级定妆。核心角色的脸、妆发和全身造型都按海报级定妆完成。角色身份和场合决定服装类别与华丽程度，便装也要有可辨识的剪裁和搭配。

### 1. 适用范围与年龄

- 男女主和核心年轻角色（含反派女配、男二）：先按身份、场合和角色处境选型，再写基线、具体五官、妆发、神态及一到两个记忆点。
- 同剧对手角色优先用服装主色区分。剧本明确同制服时，靠脸型、眼型、发型轮廓与表演拉开差异。
- 父母、长辈和路人用影视剧基线，保留与剧本相符的年龄感。豪门长辈用贴合身份的神态、发式和衣料体现贵气。
- 落魄、贫困、病中、农村适用符合处境的衣着。用可见的领肩轮廓、发型或面料层次保留主演的辨识度，按剧本设计磨损、灰尘或疲态。
- 人物年龄和整体观感与剧本匹配。成年角色在剧本允许时可适度年轻化或成熟化，长幼关系和角色身份清楚可辨。

### 2. 美感基线原文（完整版开头逐字使用）

- 现代：高颜值明星级真人形象，韩剧主演定妆照质感，明亮干净的棚拍柔光，时装大片级精修定妆。底妆清透匀净，眉眼清晰有神，鼻梁至下颌保留柔和的立体明暗，肩颈线条修长。妆发表现清楚，整套服装的轮廓、叠搭与面料细节完整。
- 古装（古代、仙侠、宫廷）：高颜值明星级真人形象，国风古装剧主演定妆照质感，电影级影棚柔光，高清精修。肤质清透细腻，眉眼明亮有神，五官立体协调，面部轮廓干净，身形挺拔修长。服装层次清楚，发式、刺绣与配饰考究。
- 长辈、路人：影视剧定妆照质感，专业影棚柔光，高清。
- 民国、港风等：把现代基线的「韩剧主演」换成对应时代或地域的影视主演风格。
- 骨相与体态（接在年龄身高之后）：女主和核心女角按年龄、气质与题材确定脸型、眉眼走势、鼻唇线条和肩颈比例。妆发落实到皮肤光泽、眼尾、唇色和正侧背可识别的发型轮廓，按居家、通勤、仪式等场合选择服装类别、妆面浓淡和配饰华丽度，各场合保持主演级完成度。男主和核心男角用男明星骨相，写清立体眉骨、眼窝层次、高挺鼻梁与清晰下颌，按角色年龄和类型调整脸宽、下颌转折、眼型与头肩比例。便服、礼服和剧情狼狈状态都沿用已定骨相与体态，衣着和妆效按当前场合变化。真人比例上做上镜优化，已确认的演员参考图优先。

### 3. 输出格式

先输出定位行：`【女主｜记忆点：××、××】`（非核心角色只写身份，如【母亲】）。类型、主色等内部确定，不单独列出。每个角色只输出一份完整版。

- **【角色名｜GPT生图完整版】**：连续中文段落，顺序：①基线原文 ②性别、剧本年龄与外表年龄、身高、身材骨相 ③脸型 ④眉、眼、鼻、唇 ⑤神态 ⑥妆容 ⑦发型发色 ⑧记忆点 ⑨配饰（没有写无）⑩上装（款式、颜色、版型、领型、袖型、长度）⑪下装 ⑫鞋袜 ⑬面料纹理与可见结构 ⑭整体配色与气质。

### 4. 写法要求

- 至少1个记忆点中景能看清（发型、发色、发饰、耳饰、主色等）。痣适合作近景细节。眼镜适合确有角色识别作用的造型，镜片低反光、镜框轮廓与发型配合，眼神清楚可见。
- 每套核心角色服装写出一个全身可辨的剪裁焦点、一组具体的材质层次，以及一处能在近景看清的工艺或配饰。日常装可用滚边、织纹、扣件或叠穿。正式造型按场合展开刺绣、镶边、层纱、缎面和成组配饰，重点集中在一处。服装主色与辅色最多三种，组织清楚的深浅关系。金属扣、首饰与刺绣等小面积细节可作点缀。
- 按角色身份选定整套穿搭，协调肩线、腰线、衣长与鞋型。松量可用于有意设计的叠穿和轮廓。鞋、配饰及面料按年代、场合和动作需求选择，制服和剧本指定服装优先。
- 核心角色以海报级主演定妆为成片标准。近看眉眼、唇妆、发丝和面料细节，全身看头身比例、肩腰线条和整套造型。采用大面积柔光、匀净精修和克制的发肤光泽，同时保留眼神光与五官起伏。生成三视图前检查特写能否看出角色的眼神和五官记忆点，侧面是否写清鼻梁、下颌、发式和服装轮廓，全身是否有一眼可辨的造型重点。
- 每个特征只写一个确定值，不写“或”“可选”。
- 同剧主要角色按美型库的选型顺序决定辨识度。剧本要求近乎同貌、被误认或共用制服时，保留所需的相像程度，并固定剧情指定的区别。
- 亲密角色可通过少量共用色呼应，关键外观线索仍须容易区分。身高差采用剧本、演员设定或合理的真人比例。
- 同一角色在完整版、三视图和视频中使用同一套识别特征。剧本换装时写对应造型，只更改这次确认需要变动的项目。

## 反推穿搭妆发与更新美型库

### 一、技能目标

把人物参考图中的造型拆解为准确、可复现、可组合、可锁定角色一致性的中文提示词。

默认忠实还原参考图，不擅自换色、改款，不添加图中不存在的主体服装和配饰。默认只输出中文，不生成英文提示词。

### 二、触发方式

用户上传人物图片并提出以下或相近要求时使用：

- 反推衣服、妆容、发型等提示词。
- 提取人物造型提示词。
- 分析角色穿搭。
- 生成同款人物提示词。
- 根据图片建立角色一致性设定。
- 提取人物三视图或四视图的造型特征。

已经进入反推流程后，用户连续发下一张人物图，或说「继续」「下一张」「这张也一样」时，沿用同一反推范围和固定输出格式。每次处理当前这张图。

### 三、固定输出格式

每次回复直接输出一个可复制的完整中文生图提示词段落，核心人物特征放在前半段。观察拆解和入库在内部完成，回复从人物描述直接起笔，只包含提示词正文。用户仅指定衣服、妆容或发型时，段落只覆盖所指定的部分。

### 四、核心反推方法

#### 第一步：确定整体方向

观察并判断：

- 现代、校园、职场、复古、礼服、古风、玄幻或暗黑等风格。
- 人物的成年年龄感、性别呈现、身份感和整体气质。
- 主色、辅色、点缀色及整体冷暖关系。
- 图片属于近景、全身图、三视图、四视图还是角色设定板。

#### 第二步：拆解服装

服装按照“从内到外、从上到下”的顺序分析，每件服装尽量写明：

`类别＋颜色＋材质＋廓形＋长度＋领型＋袖型＋结构＋装饰＋穿法`

具体包括：

- 内搭、衬衫、针织衫、外套或外袍。
- 裤装、裙装、腰线、褶量、开衩、收口或拖尾。
- 腰带、腰封、叠穿关系和露肤位置。
- 鞋履的款式、颜色、材质、鞋底或鞋跟。
- 古装补充交领、对襟、广袖、窄袖、披帛、刺绣、裙摆层数等。

无法确认准确款式或朝代时，优先描述可见结构，不强行猜测专业名称、品牌或历史时期。

#### 第三步：拆解发型

发型提示词必须尽量覆盖：

`发色＋长度＋分缝＋刘海＋顶部蓬松度＋鬓角碎发＋卷直状态＋层次＋束发位置＋发饰`

发饰需要补充颜色、材质、形状和佩戴位置。

#### 第四步：拆解妆容

妆容提示词必须尽量覆盖：

`底妆质感＋眉形眉色＋眼影色系＋眼线走向＋睫毛＋下眼睑或卧蚕＋腮红位置＋唇形唇色＋高光＋整体妆感`

男性人物也要描述适度的镜头妆感，但不能写成过度浓艳妆容，除非参考图确实如此。

#### 第五步：提取五官和气质

描述以下可见特征：

- 脸型、眉眼、瞳色、鼻梁、唇形和肤色。
- 肩颈、身材比例、站姿和体态。
- 清冷、温柔、知性、锋利、疏离、甜美、贵气等气质。

不能只写“帅气、漂亮、高级”，必须用可视化特征支撑审美判断。

#### 第六步：提取配饰和鞋包

提取眼镜、耳饰、项链、发饰、手套、腰饰、包袋、鞋袜等可见元素。图中没有明显配饰时，不凭空添加。

#### 第七步：合并完整提示词

按以下顺序合并：

`人物与成年年龄感 → 整体风格 → 五官与气质 → 发型 → 妆容 → 服装分层 → 配饰鞋包 → 姿态 → 构图视图 → 背景灯光 → 材质画质 → 一致性要求`

使用逗号分隔，删除重复同义词，避免前后冲突。

### 五、多视图和角色设定板规则

参考图属于人物三视图、四视图或设定板时，完整提示词追加：

> 人物角色设定图，左侧面部近景特写，右侧同一人物正面、侧面、背面全身视图，同一张脸，同一发型，同一套服装，人物比例统一，服装细节一致，全身完整入镜，无遮挡，纯白或浅灰摄影棚背景，柔和均匀布光，高清发丝与服装材质细节。

若图片实际布局不同，应忠实沿用图片布局，不机械套用上述构图。

### 六、美型和华丽度增强

默认保持参考图辨识度，只做轻度精致化。

用户明确提出“更帅、更美、更华丽、人物三视图特别精致”时：

- 男性强化骨相清晰、眉眼锋利、鼻梁挺直、肩颈利落和高级面料，不添加夸张肌肉。
- 女性强化五官精致、眼神通透、发丝细腻、妆面干净和服装层次，不使用幼态、儿童感描述。
- 服装华丽度通过高级面料、考究剪裁、刺绣、暗纹、珠饰、金属件和层叠关系实现。
- 不以无目的堆砌首饰代替华丽设计。
- 不改变参考图的核心发型、主色、服装类别和身份气质，除非用户要求重新设计。

### 七、古风和玄幻造型规则

- 先描述可见的领型、袖型、外袍、腰封、裙摆、披帛、纹样和发饰。
- 不确定具体朝代或服制时，不做确定性判断。
- 明显带有影视、游戏或幻想元素时，说明“影视化或幻想化设计，并非严格历史复原”。

### 八、人物年龄安全规则

- 人物年龄不明时默认按照成年人物处理。
- 现代校园造型使用“成年大学生、成年学院风”等表述。
- 不使用儿童化身体比例、幼童、未成年或类似描述。

### 九、提交前检查

- [ ] 是否只使用中文，除非用户明确要求英文。
- [ ] 是否忠实保留主色、服装类别、发型和标志性配饰。
- [ ] 服装是否写明颜色、材质、廓形、长度、结构、装饰和穿法。
- [ ] 发型是否写明发色、长度、分缝、刘海、卷直、层次、束发和发饰。
- [ ] 妆容是否覆盖底妆、眉、眼、腮红、唇和质感。
- [ ] 五官与气质是否使用可见特征，而不是只堆审美形容词。
- [ ] 不确定的品牌、历史款式或朝代是否避免被写成确定事实。
- [ ] 完整提示词是否存在颜色、结构或风格冲突。
- [ ] 多视图是否锁定同脸、同发型、同服装和统一比例。
- [ ] 是否避免儿童化比例和未成年暗示。

### 十、反推后更新美型库

完成当前图的反推后，在内部读取[人物美型库](references/appearance-library.md)，逐条比较现有类型和「可复用造型元素」。

1. 从当前图提炼少量清楚可见、能跨角色使用的特征，如起卷位置、领袖结构、面料层次、妆色分布、刺绣布局或配饰呼应。用户要求增强时新增的设计作为本次建议处理，入库只采用参考图已有的元素。
2. 按意思去重。同义词、单纯换色和已有的常见五官组合跳过。有明确新结构或新搭配关系时新增条目，同类技法的新变体合并到原条目。
3. 每条沿用库内的「类别、元素与画面效果、适用场合、来源」四列。来源使用当前附件名称或已有图号加造型简述，保留已有来源。完整提示词留在本次交付里。
4. 写入前重新读取美型库，基于最新内容合并实际增量，保留其他条目。写入后回读核对，新条目及来源正确才算更新成功。同图重复处理没有增量时保持文件原文。
5. 默认回复仍只有完整提示词。库更新在内部完成，用户问起时按实际写入结果说明。环境只读或写入失败时，在提示词后简短注明「美型库待写回」，仅在用户要求时提供待合并条目。
6. 用户明确说仅反推时，按该范围交付。以后从剧本设计新造型时，按年代、身份、场合和气质选用库内元素，再按角色重新搭配。

更新美型库由每次反推触发。
