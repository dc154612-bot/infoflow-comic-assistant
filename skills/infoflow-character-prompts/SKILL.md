# 人物提示词

## 本轮输入

- 写人物提示词时，使用当前剧本及用户确认的人物设定。已有本剧拆解稿时，用其中的出场人物和角色关系辅助定位。按需读[人物美型库](references/appearance-library.md)选类型、五官、神态和记忆点。
- 只做三视图时，读取[三视图模板](references/three-views.md)及该角色完整版原文。使用用户已确认的版本，用户要求完整流程且尚未确认角色版本时，可使用本次生成的完整版。缺少完整版时索取材料，或先完成完整流程的人物提示词步骤。
- 限定某一个角色时，逐条对照该角色原稿。新增设定标注「设计建议」。用户只要人物或三视图提示词时，交付提示词。用户要求生成三视图或跑完整流程时，有生图工具就按模板生成一人一张的参考图。生图工具不可用时，交付可复制提示词并说明图片尚未生成。

## 造型和输出

核心：**观众第一眼就想看**——女美男帅，一眼看出谁是女主、坏人、霸总，男女主像一对。

### 1. 适用范围与年龄

- 男女主和核心年轻角色（含反派女配、男二）：先按剧中身份选颜值类型（附录A），再写基线、类型五官与神态、1—2个记忆点。
- 女主与反派女配主色错开（一般女主浅色素色，反派深色艳色），剧本另有设定按剧本。
- 父母、长辈、路人用影视剧基线，不套偶像美感，不丑化；豪门长辈写出贵气。
- 落魄、贫困、病中、农村：朴素但颜值不降，服装简单合身干净，保留一个小亮点。
- 女性外表比剧本年龄小3—5岁，最低18岁观感；男性霸总、清冷等按剧本年龄（可写“成熟男人味”），少年、奶狗显年轻。

### 2. 美感基线原文（完整版开头逐字使用）

- 现代：高颜值明星级真人形象，韩系偶像定妆照质感，专业影棚柔光，高清精修。皮肤白皙通透、细腻光滑，五官立体协调，头身比优越，肩颈线条修长。服装为偶像剧精致造型，剪裁合身，面料有质感。
- 古装（古代、仙侠、宫廷）：高颜值明星级真人形象，国风古装剧定妆照质感，专业影棚柔光，高清精修。皮肤白皙通透、细腻光滑，五官立体协调，头身比优越，身形挺拔修长。服装为古装剧精致造型，层次丰富，刺绣与配饰考究。
- 长辈、路人：影视剧定妆照质感，专业影棚柔光，高清。
- 民国、港风等：把现代基线的“韩系偶像”换成对应风格。
- 身材骨相（接在年龄身高之后）：女性“纤细匀称，腰线高，腿部修长笔直”；所有男性“男明星骨相，眉骨立体，眼窝深邃，鼻梁高挺，下颌线锋利，眼神有神；宽肩窄腰，身形挺拔，腿长，比例约九头身”。

### 3. 输出格式

先输出定位行：`【女主｜记忆点：××、××】`（非核心角色只写身份，如【母亲】）。类型、主色等内部确定，不单独列出。每个角色输出两版：

- **【角色名｜GPT生图完整版】**：连续中文段落，顺序：①基线原文 ②性别、剧本年龄与外表年龄、身高、身材骨相 ③脸型 ④眉、眼、鼻、唇 ⑤神态 ⑥妆容 ⑦发型发色 ⑧记忆点 ⑨配饰（没有写无）⑩上装（款式、颜色、版型、领型、袖型、长度）⑪下装 ⑫鞋袜 ⑬面料纹理与可见结构 ⑭整体配色与气质。
- **【角色名｜豆包精简版】**：从完整版删修饰词，沿用原词不换说法；基线压成一句，②—⑭都保留。

### 4. 写法要求

- 至少1个记忆点中景能看清（发型、发色、发饰、耳饰、主色等）；痣只作第二记忆点；不首选眼镜。
- 服装公式：合身主单品 + 1—2个设计亮点（领口、袖型、叠穿、收腰、百褶、开衩等）+ 1—2件配饰 + 显比例的下装和鞋。配色最多3种，有深浅对比；写清面料和领型、扣件等结构。
- 比例：女性腰线高，优先高腰短裙、及膝裙、高腰短裤或配跟鞋的阔腿裤，平底鞋只配短下装；男性衣摆塞进裤腰或短外套，修身直筒或锥形裤，配切尔西靴、德比鞋、乐福鞋、马丁靴或干净板鞋。外表22岁以上不用背带裤、中筒袜、卡通图案（校园剧除外）。
- 核心角色禁止：普通、路人感、生活化、自然毛孔、皱纹、纪实、生活照；纯色短袖衬衫配中长A字裙配平底鞋、针织Polo衫、宽松休闲直筒裤、全身浅色无对比、土色系、凉拖。
- 每个特征只写一个确定值，不写“或”“可选”。
- 同剧主要角色类型、记忆点不重复；脸型、眼型、发型轮廓、主色至少3项明显不同。
- 男女主配色呼应（共用一色或同色系一深一浅），男比女高约15—20厘米。
- 同一角色在提示词、三视图、视频中设定一致；剧本明确换装时另出服装。
