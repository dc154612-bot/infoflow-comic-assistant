# 剧本拆解

读取本轮指定的正文、配音稿和已有时间点。正文与配音稿有差异时，剧情理解参考正文，音频内容和时间以确认后的配音稿为准。无法确定采用哪个配音版本时，指出具体差异。

1. 用一到三句话交代题材、核心冲突和正文的推进方向。
2. 按首次出场列出人物，写清剧本已经交代的身份、关系和当前目标。标出会影响后续制作的情绪变化、关键动作或道具。存疑处标「待确认」。
3. 按故事顺序拆出剧情节点。用表格列出「区间或节点」「涉及人物」「发生了什么」「需要保留的动作或道具」。按需摘出短句定位，引用保持原文。
4. 有真实时间点时，按每十秒归组，默认处理零至四十秒，已知配音不足四十秒时按实际终点收尾。跨组的句子按配音原时间对齐，保留前后承接。只有总时长时，按剧情顺序写节点并标注「需按实际音频对齐」，不把推测时间标成已确认的切点。

用户明确要求查看剧本拆解时，按上述格式交付。默认人物提示词流程或完整流程中，拆解在内部完成，人物清单和剧情节点用于后续制作。
