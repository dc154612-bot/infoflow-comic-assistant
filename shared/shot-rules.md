# 分镜共用规则

适用于正文、八个开头和补镜。

- 用中文。允许阿拉伯数字、画幅比例、剧本已有的外文专名、GPT、T恤、V领等通用例外。
- 【对应音频】逐字使用原文，标点与顺序不变，同一段音频不得跨组移用。
- 只表现原文已有剧情、行为、道具和因果。可以补自然的表情、视线和动作衔接。
- 时间轴用整数秒。真实边界四舍五入，每镜至少一秒。横线前后秒数以镜头标题为准。

## 七字段格式

正文使用分组标题。八个开头使用方案标题。补镜沿用用户指定的原镜头标题。

```
分镜头组1｜0—10秒

镜头1｜0—3秒
【对应音频】原文
【景别】一个景别词
【人物动作与表情】角色名 + 一个主要动作 + 表情、视线、道具互动 + 说话状态
【走位】左右、前后、朝向、距离，与门、床、桌等已有物体的相对位置，移动路线
【镜头运动】一个主要运镜；需要时加景别变化（如：缓慢拉远至中景）或视角
【光线】光源、方向、冷暖、明暗
【时间】剧情时间 + 时段（如：第七年春，白天）；剧本没写只写时段
```

- 景别范围：大远景以环境为主，远景人物全身较小，全景头到脚，中景膝盖以上，中近景腰部以上，近景胸部以上，特写面部或单个物体，大特写局部。景别变化写起始景别，变化写进【镜头运动】。
- 【人物动作与表情】不写站位、运镜、光线、心理分析；【走位】不写服装、运镜、光线、场景设定句。
- 运镜选一个：固定镜头、缓慢推近、缓慢拉远、向左平移、向右平移、跟拍、上摇、下摇、缓慢升起、缓慢下降、手持轻微晃动；视角可加平视、俯拍、仰拍、过肩、侧拍、背拍、主观视角。不用环绕、甩镜、急推急拉、多段组合运镜。
- 【光线】只写光，不写象征；【时间】不写秒数。
- 每镜一个主要动作，可带轻微反应；复杂动作拆镜或简化；说话镜头的主要动作就是说话。可补自然的视线、表情、停顿和衔接，不新增剧情。
- 不新增字段（如【对口型】【导演意图】【自检结果】）。

默认七字段。仅在用户明确要求时，在【时间】之后加【场景】。
【人物动作与表情】中的外貌由人物提示词负责，此字段不写服装、配饰、发型、妆容、五官。

## 动作与台词

- **动作与台词分镜**（正文、开头及补镜适用），如“她把协议拍在桌上，冷声说：‘签字吧。’”：
  - 动作镜：对应动作描述的音频，人物完成动作，不开口。
  - 台词镜：对应台词的音频，人物保持动作完成后的状态说话，只带表情、视线和轻微反应；景别或视角与动作镜区分（如中景切近景或过肩）。
  - 切点在两段音频交界处，四舍五入到整秒。
  - 例外：动作部分只是“他说”“她冷笑道”这类提示语，或不足1秒时，并入台词镜写成神态；原文明确“一边……一边说”的按原文同镜。
  - 原文没写动作的台词，不自行添加主要动作。
  - 拆分后超出每组3—4镜时，优先保留动作、台词分镜，合并同组相邻旁白片段。

## 对口型

- 说话镜头在【人物动作与表情】写明“××开口说话，口型对应本句”，其他人倾听不开口；纯旁白、心理活动写“画外旁白，人物不开口”。声音归属以剧本和配音为准。
- 难对口型时自行调整：先简化动作和运镜；仍困难时切到听者反应、手部或已有道具、过肩或背面，原说话者声音作画外音继续。不删词、改词、变速，不让别人代说。
- 替代镜头保持前后镜的站位、视线、手别、道具和动作进度。

## 交付前复查

复查字段、景别、音频、整数秒、口型归属及前后镜的站位、手别、道具、视线、动作和情绪。发现问题先修正。只在用户要求时提供复查说明。
